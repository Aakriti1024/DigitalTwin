# Project Report (Prototype Stage)

This directory contains the complete LaTeX source code and visual diagram assets for the UCS503 Software Engineering Mid-Semester Evaluation report.

## Files
- `report.tex`: Master LaTeX report document.
- `dfd0.png`: Clean, white-background DFD Level 0 (Context Diagram).
- `dfd1.png`: Clean, white-background DFD Level 1 (Modular System Diagram).
- `dfd2.png`: Clean, white-background DFD Level 2 (Process 2.0 Predict RUL Decomposition).
- `use_case_diagram.png`: High-resolution export of the system use-case model.

## Instructions for Overleaf Compilation
1. Create a new blank project on [Overleaf](https://www.overleaf.com/).
2. Upload `report.tex` to the project root.
3. Upload `dfd0.png`, `dfd1.png`, and `dfd2.png` directly to the project root (do not place in subfolders).
4. *(Note: `class_diagram.png` and `sequence_diagram.png` will be uploaded once exported from draw.io).*
5. Set compiler to **pdfLaTeX** and click **Recompile**.
